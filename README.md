# Hospix - Projeto Hospitalar

Projeto para seminario de Engenharia de Software com duas versoes do mesmo sistema hospitalar:

- `hospital-legacy`: implementacao funcional propositalmente mal estruturada, usada como comparativo.
- `hospital-engineered`: implementacao com Clean Code, SOLID, DDD, Clean Architecture e BillingService separado.

Diagramas principais:

- `diagramas-projetos.html`
- `hospital-legacy/docs/diagrama-arquitetura.html`
- `hospital-legacy/docs/diagrama-classes.html`
- `hospital-engineered/docs/diagrama-arquitetura.html`
- `hospital-engineered/docs/diagrama-classes.html`

Cada pasta possui README proprio com comandos para rodar backend, frontend e fluxo de demonstracao.
