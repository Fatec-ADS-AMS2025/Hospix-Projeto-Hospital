hospital-legacy

UML Use Case Diagram

Casos de uso da versao legacy. O usuario executa o fluxo hospitalar completo, mas todos os casos passam por uma API/service centralizado.

Atores

Medico, enfermagem e administracao acessam o mesmo sistema sem controle real de permissao.

Alta

Dar alta inclui validar pendencias e gerar fatura dentro do mesmo service.

Problema

Os casos de uso existem no produto, mas nao aparecem como organizacao clara no codigo.
